# UI Screenshot Instructions

To generate a UI screenshot for the VaultPay dApp:

## Steps to Run the Application

1. **Start Hardhat Node** (Terminal 1):
   ```bash
   npm run node
   ```

2. **Deploy Contracts** (Terminal 2 - after node is running):
   ```bash
   npm run deploy:local
   ```
   Copy the deployed addresses to `frontend/src/config.ts` if not already updated.

3. **Start Frontend** (Terminal 3):
   ```bash
   cd frontend
   npm run dev
   ```

4. **Configure MetaMask**:
   - Add custom network: RPC `http://127.0.0.1:8545`, Chain ID `31337`
   - Import test account private key from Hardhat node output

5. **Open Browser**:
   - Navigate to `http://127.0.0.1:5173`
   - Connect wallet
   - Use faucet to get tUSD
   - Test create/claim/cancel payment flows

6. **Take Screenshot**:
   - Capture the UI showing connected wallet, balance, and payment interface
   - Save as `screenshot.png` in the project root

## Expected UI Features

- Wallet connection status
- tUSD balance display
- Faucet button to get tokens
- Approve token spending
- Create payment form (recipient, amount, deadline, memo)
- Claim payment button
- Cancel payment button
- Transaction status display

## Note

The core implementation is complete and all tests pass. This screenshot is optional for the submission but demonstrates the frontend integration.
